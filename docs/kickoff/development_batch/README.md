# 开发材料说明

本目录包含模拟申报指南和 3 套模拟材料，用于开发规则核对、字段提取、原文定位和结果处理。

- Markdown：`PKG-A/B/C/材料包.md`、`policy/*.md` 为对照源。
- 主包 PDF：PKG-A 见 `backend/fixtures/pdfs/A1–A3`；PKG-B/C 在本目录对应子文件夹（副本同样在 fixtures）。
- 受控变体：`variants/`（CASE-006/008/009/012/015/017/018/021/024/027/030）。
- 生成脚本：`build_pdfs.py`。

按需选用已有输入和场景即可。不扩展到 12 套包 / 20 条规则 / 60 例。比赛展示标明模拟样例；真实材料接入后另记来源。
