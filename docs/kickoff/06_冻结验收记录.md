## 直接开始开发

先选两份材料的申请经费核对，通过云端 API 提取金额和位置，接上程序比较、问题卡和原文高亮，再做修改后重审。

已有内容可以直接使用，不需要先填完签字表、补齐真实材料配额或跑完全部30例。应用开发顺序见 [八周行动计划](../competition-review/第一轮全面诊断与八周行动计划.md)。
