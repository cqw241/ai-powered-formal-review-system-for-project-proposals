## 冻结检查

- [ ] 主批次明确，政策原件与补充通知已登记；冲突关系有处理去向。
- [ ] 已选10条规则尽量覆盖至少4类检查逻辑，未自动化条款不静默遗漏。
- [ ] 每条规则有政策来源、适用条件、例外、证据需求及缺失/未知处理。
- [ ] 30例均有可访问输入/准确位置、唯一预期、理由和双人复核；不是30个标题。
- [ ] 案例覆盖正常、违规、关键边界、缺失、未知及真实存在的例外/冲突；构造数据有标记。
- [ ] 分歧未解决项不计入已确认数，明确哪些规则可以启动开发。
- [ ] 当前开发材料和变体不会流入后续独立盲测分区。
- [ ] 敏感原件留在授权存储；仓库仅放允许公开/内部共享的索引与摘录。
- [ ] 全部状态如实标记：本次只冻结开发输入，不代表代码已实现、已测试或规则已发布。
