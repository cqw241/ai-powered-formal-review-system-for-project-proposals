# 01 批次与支持范围

状态：待填写、待业务确认。以下是启动模板，不是已冻结批次。

**今天够用的数量：1个真实申报批次＋完整政策资料＋至少3套真实申报材料＋10条确认规则＋30个完整案例。**第一周末扩到12套开发材料、20条规则和60例；发布规则前再补足每条至少6个有意义测试。500—800是后期Policy Atom语料目标，不是今天要整理的规则数。实际政策没有那么多规则时不拆凑数量。

## 范围冻结原则

- 原政策资料完整收齐并登记；首日10条仅是开发子集，其他条款在03中登记去向。
- 同一批次只采用经业务人员确认的政策组合，冲突或生效关系不明的条款保留待确认。
- 材料清单不完整、关键文件未上传时，不能将“未找到”认定为“已确认不存在”。
- 后续改变政策、材料或规则范围时更新版本，保留本次冻结记录。
