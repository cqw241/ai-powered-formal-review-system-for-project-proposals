# 01 批次与支持范围

本目录使用模拟开发批次，现有规则与材料可直接用于功能开发。

| 字段 | 开发基准 |
|---|---|
| 批次ID | KICKOFF-2026-09-10-DEV-A |
| 名称 | 2026青年科研创新培育计划 |
| 类别 | 自然科学、人文社科 |
| 审查阶段 | 提交前形式自检 |
| 规范版本 | 2026-v1.0 |
| 申报截止日 | 2026-09-30 |

已有1份模拟指南、3套 Markdown 材料、10条规则和30个场景说明，按正在实现的功能选用。PDF上传和定位联调需准备对应PDF文件。

下文“包已冻结”仅指本次提交文件集合已确定。更新材料时产生新版本。

## 支持矩阵

| 要求 | 本次处理方式 | 规则ID | 主要证据 | 关键边界 |
|---|---|---|---|---|
| 三类必需材料完整性 | 检查提交文件清单 | RULE-001 | Material Manifest | 包未冻结/未分类不能直接判缺件 |
| 项目名称跨文件一致 | 自动 | RULE-002 | 申报书/预算/承诺书标题 | 仅归一化空白差异 |
| 项目负责人跨文件一致 | 自动 | RULE-003 | 三类材料负责人字段 | OCR不稳定转人工 |
| 项目周期 | 自动 | RULE-004 | 起止日期 | 2027-01-01至2028-12-31，最长24月 |
| 分类经费上限 | 自动 | RULE-005 | 项目类别+申请金额 | 自然30万、人文15万 |
| 预算科目合计 | 自动 | RULE-006 | 科目金额+总额 | 允许≤1元四舍五入差 |
| 申报书/预算金额一致 | 自动 | RULE-007 | 两处金额 | 统一元/万元后比较 |
| 大额设备必要性附件 | 检查附件清单 | RULE-008 | 单台设备金额+附件清单 | ≥5万元触发 |
| 数据/伦理适用性 | 辅助人工 | RULE-009 | 研究对象、数据来源、审批号 | 无法确认适用性时HUMAN |
| 承诺书签署日期 | 自动 | RULE-010 | 签署日期+截止日 | 签名真伪不自动判断 |

## 明确不自动判断

系统不自动输出学术价值、创新性、最终资格、伦理实体有效性、签名真伪。上述内容只能由人工或外部权威系统确认。
