# 05 结论真值表

状态：启动讨论参考稿，待业务负责人和独立复核者确认。用于把规则与案例的口径写清，不代表原方案全部契约修订已经完成；代码实现前同步主方案§19、§40.6及相关Schema，未完成不能发布自动结论。

| 已明确的条件 | 参考结果 | 必须保留的依据/边界 |
|---|---|---|
| 规则适用，所有必要支持证据可靠，规则计算成立 | 规则级PASS | 适用依据、支持证据、计算及本规则通过所需范围 |
| 足以推翻规则的明确反例已经核验，相关例外已排除 | 规则级FAIL | 反例和政策；其他规则或整个包可以仍未完成 |
| 必需附件义务明确，已冻结完整材料包并检查完所有可能来源，确认附件不存在 | 本次包缺件FAIL | 材料清单/快照与不存在证书；不声称申请人现实中从未拥有附件 |
| 文件未上传完、损坏或未分类，无法确定是否缺附件 | NEED_HUMAN_REVIEW；可恢复系统故障先恢复 | 缺少什么、失败文件或范围，不冒充已确认缺失 |
| 关键值模糊、图文冲突、缺表头导致口径无法确认 | NEED_HUMAN_REVIEW | 不确定值/位置及需要补充的证据 |
| 适用性或例外不明确 | NEED_HUMAN_REVIEW | 未决项必须进入账本，不从完成分母消失 |
| 有可靠依据明确不适用 | NOT_APPLICABLE | 不适用条件及来源，不计入PASS |
| 政策明确是非强制建议且应提醒 | WARNING | 保留建议性质，不改为强制违规 |
| 普遍/负向要求的检查范围未完成，尚无足够独立反例 | 不能PASS；无法继续时NEED_HUMAN_REVIEW | 剩余范围、未读页或候选；仅找到部分证据不能提前放行 |
| 负向扫描执行完成，没有检出问题 | 仅在已确认检测能力与范围内形成结果 | 执行完成不证明零漏检；高不确定语义类规则按支持矩阵交人 |
| 服务异常导致任务无法完成，恢复预算已耗尽 | SYSTEM_ERROR | 故障原因、可恢复动作；不得当成材料业务违规 |

“范围未完成”“任务运行中”属于执行状态，并不要求立即发布人工结果。每个具体CASE必须注明是在运行中、终止后还是恢复耗尽后，从而得到唯一预期。
