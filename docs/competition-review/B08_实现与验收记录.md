## 2. 技术选型与模块边界

| 层 | 选型 | 边界说明 |
|---|---|---|
| 提取 | 原生 PDF 文本 + `find_tables` | 类别走申报书；科目只取「科目 / 金额」表，不把设备明细或分年度表加进合计 |
| 金额 | 复用 `money.py` / `funding_extract.py` | 表内「金额（元）」无单位时按元解析；未知值不当 0 |

| 执行器 | `Session + RuleExecutionContext → RuleExecutionResult` | 不写 `review_items`，不发明工作台状态 |

入口：`execute_budget_rule`。`PASS`/`FAIL`/`NEED_HUMAN_REVIEW`/`SYSTEM_ERROR` 与公共契约一致。

## 3. 规则行为

### RULE-005 分类申请经费上限

| 条件 | 结论 |
|---|---|
| 类别已知、金额已知、未超绑定上限 | PASS |
| 类别已知、金额已知、明确超出 | FAIL（摘要含申请额、上限、差额） |
| 无申报书、类别缺失/无法归入两类、快照上限未知、快照类别与项目类别不一致、金额无法读取 | NEED_HUMAN_REVIEW |
| 执行异常 | SYSTEM_ERROR |

「没找到」不当 FAIL。自然科学类 300000 元等于上限为 PASS。

### RULE-006 预算科目合计一致

| 条件 | 结论 |
|---|---|
| 明细合计与申请总额绝对差 ≤ 1 元 | PASS |
| 差额 > 1 元且科目可靠 | FAIL（摘要含合计差额） |
| 缺预算表、科目不可读、金额无法解析、出现「其中：配套经费」等口径不清 | NEED_HUMAN_REVIEW |

合计行（合计 / 科目合计 / 年度合计）不计入明细。A2 中的设备采购测算、分年度表不参与 RULE-006。
