## 2. 规则行为

### RULE-001 三类必需材料完整性

| 条件 | 结论 |
|---|---|
| 申报书、经费预算表、承诺书均已 READY 且可读 | PASS |
| 清单已冻结（无 PROCESSING），三类中任一明确不存在 | FAIL（缺件） |
| 尚未提交、仍有文件 PROCESSING、或该类别文件损坏 | NEED_HUMAN_REVIEW（不把尚未找到当成确认缺件） |

### RULE-008 大额设备必要性附件

| 条件 | 结论 |
|---|---|
| 适用且存在设备必要性说明文件 | PASS |
| 所有单台/套 < 5 万元，或预算载明无此类设备 | NOT_APPLICABLE |
| 适用、包已冻结、附件明确不存在 | FAIL（缺附件） |
| 设备只有总价/无单价，或包未冻结 | NEED_HUMAN_REVIEW |

### RULE-009 数据与伦理适用性

| 条件 | 结论 |
|---|---|
| 明确不涉及人体受试者/敏感信息/生物样本/受限制数据 | PASS |
| 明确涉及且有审批编号或进行中证明（仅形式） | PASS |
| 明确涉及、提交时须提供、冻结包中既无编号也无进行中证明 | FAIL |
| 适用性、授权或伦理义务关系不清 | NEED_HUMAN_REVIEW（摘要含依据和待确认问题） |

`NOT_APPLICABLE` 写入 `check_status`，工作台条目为已完成，不计为 PASS。

## 3. 验收对照

八周计划验收句：

| 验收项 | 结果 | 证据 |
|---|---|---|
