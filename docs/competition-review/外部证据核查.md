## 模型与运行时

Qwen3.8 的视觉能力直接用于应用开发。云端 API 先接通实际功能，本地部署时再查 vLLM；Pi 资料在选用对应组件时参考。

| 对象 | 已有资料 | 使用场景 |
|---|---|---|
| Qwen3.8-27B | [官方仓库](https://github.com/QwenLM/Qwen3.8/blob/main/README.md)、[模型卡](https://huggingface.co/Qwen/Qwen3.8-27B) | 模型接入与图像输入 |
| vLLM | [v0.29.0 Release](https://github.com/vllm-project/vllm/releases/tag/v0.29.0)、[工具调用文档](https://docs.vllm.ai/en/latest/features/tool_calling/) | 应用完成后安排本地服务时查阅；不预先锁死版本 |
| Pi Agent | [v0.85.1 README](https://github.com/earendil-works/pi/tree/v0.85.1/packages/agent)、[类型定义](https://github.com/earendil-works/pi/blob/v0.85.1/packages/agent/src/types.ts) | 采用 Pi 时查模型循环、工具与取消接口 |
| pi-ai | [v0.85.1 README](https://github.com/earendil-works/pi/tree/v0.85.1/packages/ai) | 模型 Provider 与图文调用适配 |

已有源码记录中，Pi 的 `shouldStopAfterTurn` 在当前响应和工具结束后检查；工具批次提前停止取决于整批结果。若实现取消功能，应处理正在执行的请求和任务状态，不能只依赖该回调。具体行为以采用版本的 [agent-loop 实现](https://github.com/earendil-works/pi/blob/v0.85.1/packages/agent/src/agent-loop.ts) 为准。
