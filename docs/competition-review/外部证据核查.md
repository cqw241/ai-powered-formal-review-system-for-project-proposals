# 规证 AI 外部证据核查

核查日期：2026-09-10。范围：一手官方模型资料、固定版本源码、文档处理产品及高校科研管理公开材料。本文是第一轮外部证据附件，不代表已运行模型、购买产品或验证本项目效果。主方案只按设计材料理解，不把接口示例当作已实现代码。

## 1. 对参赛判断最有影响的结论

1. **【已核验】Qwen3.8-27B、Claude Fable 5.1、Gemini 3.8 Flash、vLLM v0.29.0、Pi v0.85.1 均有真实官方来源。** 不能因训练记忆较旧而断言这些名称虚构。真正风险是具体链路与任务精度尚未见项目实测。
2. **【推断】“上传申报书和政策，AI 找问题并给报告”已经落在通用模型能力范围，单靠此流程缺乏强差异化。** 下列官方文档能证明文档理解、结构化提取、视觉定位等基础能力存在；不能证明任何通用模型在本项目上已达到合格率或召回率指标。
3. **【已核验】科研形式审查不是空白市场。** 厂商早已有 AI 形式审查方案，高校采购需求已有自动资格筛查。不能宣传“首个 AI 科研形式审查系统”；可以竞争的是受控政策版本、证据范围完备性、跨材料核验、拒判边界和整改复审可验证效果。
4. **【风险】坐标输出协议不等于定位正确，更不等于事实正确或没有遗漏。** 尤其不得由同一模型二次确认推导“独立验证已经消除幻觉”。
5. **【建议】保留现有受限运行时适配器；把第一周投入用于实测最小技术链与强 Baseline。** 不应基于名称真实性问题推倒重建，也不应把成功接通工具调用当成审查系统可靠性证明。

## 2. 模型与 API 核验

| 对象 | 官方资料与日期 | 已确认内容 | 项目需要另行证明 |
|---|---|---|---|
| Qwen3.8-27B | [Qwen 官方仓库](https://github.com/QwenLM/Qwen3.8/blob/main/README.md)，News 明确 2026-08-14 | 27B 权重发布；有 vLLM 启动示例，含 reasoning parser、auto tool choice、tool-call parser | 当前机器、量化方式、上下文、并发与图像预算下的可用性 |
| Qwen 模型卡 | [Qwen/Qwen3.8-27B](https://huggingface.co/Qwen/Qwen3.8-27B)，本次读取于 2026-09-10 | Image-Text-to-Text、Apache-2.0；图文 API 示例；可调 reasoning_effort，默认深推理 | 官方卡未给本项目 0–1000 中文文档证据框精度承诺；未发现本领域缺失证据检测验证 |
| Claude Fable 5.1 | [Anthropic 模型页](https://www.anthropic.com/claude/fable)，发布项为 2026-09-01 | 正式模型/API ID `claude-fable-5-1`；页面标价每百万输入/输出 token 为 10/50 美元 | 中国高校部署可用性、授权与项目实测；不要据官方综合榜单宣称审查准确率 |
| Gemini 3.8 Flash | [Google 发布公告](https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/)，2026-09-02 | 已发布；公告介绍价每百万输入/输出 token 为 0.75/3.75 美元 | 价格有期限和适用条件；真实人民币单件成本须含重试、图像、缓存、工具与人工 |
| Gemini API | [最新模型迁移说明](https://ai.google.dev/gemini-api/docs/latest-model)，更新 2026-09-03 | API ID `gemini-3.8-flash`；使用 thinking_level；部分旧采样参数已不支持 | 不要把旧 Gemini 配置原样用于新模型；固定请求与响应样例做兼容检查 |

**通用模型覆盖范围。** Claude 官方 [PDF 支持](https://platform.claude.com/docs/en/build-with-claude/pdf-support)说明可处理文字、图片、图表并提取结构化信息；当前文档给出 32 MB 请求限制及依上下文而异的 600/100 页上限，密集材料可能更早触顶。Gemini 官方 [文档理解](https://ai.google.dev/gemini-api/docs/document-processing)明确支持 PDF 原生视觉、表格、结构化输出，文档页数上限可达 1000。两页为持续更新文档，核验日为 2026-09-10。这些能力足以构成强直接调用 Baseline；与生产审查责任、规则发布、全量遍历和复审状态一致性仍是不同层面。

**定位协议不能跨厂商照搬。** Gemini [图像理解](https://ai.google.dev/gemini-api/docs/image-understanding)采用 0–1000，示例次序为 `[ymin,xmin,ymax,xmax]`。Claude [视觉文档](https://platform.claude.com/docs/en/build-with-claude/vision)说明采用处理后图像的绝对像素坐标，定位是近似值。Qwen3.8-27B 的已读官方模型卡不足以确认其原生坐标契约与项目精度。这里是“未核实”，不是“没有能力”。

**【建议】统一内部坐标，但在 Provider Adapter 明确保存原始坐标、原点、轴序、缩放、padding、裁剪与页变换；用人工框核验，不靠统一 JSON 字段名掩盖差异。** 本项目应以同页原生文字坐标、OCR 字符对齐、局部视觉为互补证据；对签章只核验可见存在与位置，不推断真伪或授权有效性。

## 3. vLLM 与 Pi 固定版本核验

### vLLM

**【已核验】** [v0.29.0 Release](https://github.com/vllm-project/vllm/releases/tag/v0.29.0)存在，页面显示 9 月 9 日发布，commit 前缀 `98dff2a`；本次核查时刚发布约一天。版本存在不等于特定 GPU/量化/Qwen 多模态工具调用组合稳定。

[当前 tool calling 文档](https://docs.vllm.ai/en/latest/features/tool_calling/)区分 auto/required/named function 的约束解码行为；auto 自由生成与启用 strict 的行为不同。**【风险】该链接为 latest，本次固定版本文档 URL 抓取失败，不能把 latest 每项行为直接担保为 v0.29.0 行为。** 验证应使用固定镜像与实际 schema，不把“OpenAI-compatible”理解为全部高级参数语义完全一致。

### Pi 运行时接口：并非伪造，但须理解停止语义

[v0.85.1 Agent README](https://github.com/earendil-works/pi/tree/v0.85.1/packages/agent)可直接对照主方案 §21：`Agent`、`streamFn`、`toolExecution`、`beforeToolCall`、`afterToolCall`、`shouldStopAfterTurn`、`abort()`、`waitForIdle()` 均存在；图像输入示例存在。只读核验，未运行或安装。

| 主方案写法 | 源码确认 | 诊断 |
|---|---|---|
| `beforeToolCall({toolCall,args})`，返回 block/reason/terminate | [types.ts，BeforeToolCallResult](https://github.com/earendil-works/pi/blob/v0.85.1/packages/agent/src/types.ts#L55) | 参数与返回字段正确；args 是 schema 校验后参数 |
| `afterToolCall({toolCall,result,isError})` | [types.ts，AfterToolCallContext](https://github.com/earendil-works/pi/blob/v0.85.1/packages/agent/src/types.ts#L100) | 正确；还可取得 args/context |
| `return {...result, terminate:true}` | [types.ts，AfterToolCallResult](https://github.com/earendil-works/pi/blob/v0.85.1/packages/agent/src/types.ts#L65) | 合法；回调是部分覆盖，无深度合并。只回 `{terminate:true}` 更简洁，不能误报为 API 错误 |
| Tool 的 `executionMode` | [types.ts，AgentTool](https://github.com/earendil-works/pi/blob/v0.85.1/packages/agent/src/types.ts#L357) | 确实存在，支持 sequential/parallel |
| `new Agent({initialState,streamFn,toolExecution})` | [agent.ts，AgentOptions](https://github.com/earendil-works/pi/blob/v0.85.1/packages/agent/src/agent.ts#L91) | 结构与方案匹配；models/provider/model 的实际创建仍要集成验证 |

**最关键的真实限制：** [agent-loop.ts 的 shouldTerminateToolBatch](https://github.com/earendil-works/pi/blob/v0.85.1/packages/agent/src/agent-loop.ts#L553)只有在整批所有最终工具结果均 `terminate:true` 时才提前停止；混合批次会继续。`shouldStopAfterTurn` 在当前模型响应和工具正常结束后执行，不能充当运行中超时熔断。源码另见 [Agent README 停止语义](https://github.com/earendil-works/pi/tree/v0.85.1/packages/agent)。

**【建议】** 为 `request_human_review` 持久化任务终态，业务调度器据此取消后续工作；当前工具使用 AbortSignal/超时，落库用 task revision 或租约校验阻止迟到结果覆盖。验证“人工复核请求与普通工具同批”“取消时工具未结束”“审计写失败”三个用例。不要仅把 terminate 设为 true 就声称所有工作立即停止。

**【风险】** 主方案 post-processing 文字写了 Schema Validation/字段清理，但展示代码只记录日志再回传 result；这只是样例与工程验收之间的缺口，不能据此认定实际实现已经存在漏洞。

[v0.85.1 pi-ai README](https://github.com/earendil-works/pi/tree/v0.85.1/packages/ai)明确支持 OpenAI-compatible API（含 vLLM），有 Models/provider 注册及图文工具调用能力。接入路径合理；底层模型的工具成功率与检索策略收益不能由 SDK 功能列表代替。

## 6. 可直接用于方案修订的验证动作

以下为**【建议】**，不是来源声称有效的已完成实验。

1. **两天内完成链路冒烟。** 固定 Qwen 权重 revision、vLLM 镜像 digest、Pi lockfile；拿 20 页包含数字 PDF、扫描、旋转、小字、跨页表格的许可材料。验证图片传递、一次合法工具、一次参数错误、一次禁止工具、取消/超时、结构化输出及坐标映射。每条保留请求、脱敏结果与失败分类。
2. **一周内完成视觉定位门槛。** 200 个独立人工框，测定位与文本匹配、关键字段精确正确率；注入错页、轴序颠倒、缩放/padding 不一致，确认 Validator 拒绝。整体 IoU 不能替代姓名/金额字段正确性。
3. **强通用模型 Baseline。** 对同一批政策及申报包，给强模型相同可用资料和合理 Prompt，让其输出条目化审查与引用；再比较“规则/解析器”“同底座结构化工作流”“完整引擎”。按缺陷召回、误拒、危险通过、人工复核分钟数与单件成本分解，避免只证明本地小模型不如自家复杂系统。
4. **市场壁垒验收。** 至少一个真实授权批次，来自不同学科；科研管理人员双人标注并解决分歧。现场展示政策版本、证据原页、解释、复核与整改后仅重算受影响规则；公开适用规则覆盖率和拒判比例。可以证明可靠性工程与数据资产，而不是基础模型研发创新。

- Qwen3.8-27B 对本项目视觉证据的 0–1000 原生坐标保证与独立测试表现。
