## 当前开发方向

- 目标是完成校内比赛应用，先跑通上传、规则核对、原文定位、人工修正和重审。
- 开发阶段使用云端 API；应用完成后再考虑本地 vLLM。
- Qwen3.8 视觉能力作为可用能力直接使用。
- 规则和案例按正在开发的功能选用。
- 技术选型、Prompt、Schema和接口随实现确定；优先简单模块和整包重审。
- 必要检查围绕当前功能与具体故障，保留规则计算、页面定位和状态处理的基本正确性。
