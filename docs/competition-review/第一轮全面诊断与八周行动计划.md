# 规证AI：八周开发分支与验收计划

更新日期：2026-09-14。

## 开发重点

完成“上传材料 → 规则核对 → 原文定位 → 人工修正 → 补件重审”的应用。产品范围见 [参赛方案](../../规证AI_参赛方案.md)。

文档处理先使用云端多模态 API 与 PDF 原生文本；开发中若完整表格或拍照材料解析成为具体阻塞，再按需接入约 1.2B 参数的 TeleOCR。应用完成后再考虑本地 vLLM。

## 分支交付方式

每周完成3条分支，共24条。表中分支名用于创建开发分支；“依赖”指开始联调前需要合入的分支编号。独立页面和模块可提前开发，依赖满足后完成串联。

每条分支完成对应操作、达到表中结果并合入开发主线后计为完成。PR写明操作入口、使用材料和实际结果；检查围绕本条改动，修复问题时保留相关回归用例。

使用 [现有开发材料](../kickoff/02_政策与材料索引.md) 按功能准备输入。金额、日期等规则按 [首批规则清单](../kickoff/03_首批规则清单.md) 实现；验收以应用中的操作与结果为准。
