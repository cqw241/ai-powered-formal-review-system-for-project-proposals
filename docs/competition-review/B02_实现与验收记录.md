## 2. 技术选型与模块边界

| 层 | 选型 | 边界说明 |
|---|---|---|
| 前端 | React + TypeScript + Vite | 详情页：上传区、材料列表、页图翻页、本页文本 |
| 后端 | FastAPI + SQLAlchemy | 同步上传与解析；无后台队列 |
| PDF | PyMuPDF | 页数、原生文本、PNG 渲染；页码对外从 1 开始 |
| 存储 | 本地目录 `MATERIALS_DIR` | 文件名使用材料 UUID，拒绝路径穿越 |
| 数据库 | SQLite `materials` 表 | 重启保留记录；`create_all` 不清空 |

关键模块：

- 材料 API：`backend/app/api/materials.py`
- PDF 服务：`backend/app/services/pdf.py`、`storage.py`
- 模型：`Material`（`backend/app/models.py`）
- 前端：`frontend/src/App.tsx`、`api.ts`、`types.ts`

## 3. 已实现 API / 配置

### API

| 方法 | 路径 | 行为 |
|---|---|---|
| POST | `/api/projects/{project_id}/materials` | multipart：`file` + `category`；同步解析 → `READY`/`FAILED` |
| GET | `/api/projects/{project_id}/materials` | 材料列表，创建时间倒序 |
| GET | `/api/materials/{id}/pages/{page}/text` | 原生文本；越界 400 |
| GET | `/api/materials/{id}/pages/{page}/image` | PNG；越界 400 |

类别：`APPLICATION` / `BUDGET` / `COMMITMENT` / `OTHER`  
状态：`PROCESSING` / `READY` / `FAILED`

### 配置

见 `.env.example`：`MATERIALS_DIR`、`UPLOAD_MAX_BYTES`（默认 20MB）。

## 4. 复现步骤

```bash
# 后端
cd backend
uv sync --extra dev
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000

# 前端
cd frontend
npm install
npm run dev
```

浏览器打开项目详情 → 选择类别并上传 PDF → 点击就绪材料 → 翻页查看页图与文本 → 刷新 / 重启后端后仍可预览。

测试样例：`backend/fixtures/pdfs/A1_项目申报书.pdf`（3 页）、`A2_经费预算表.pdf`（2 页）、`A3_科研诚信与合规承诺书.pdf`（2 页）。

## 6. 已知限制与 B03 入口

- 无登录、无删除/替换/材料版本。
- 上传为同步处理；前端在请求期间显示「上传处理中」。
- 不支持加密 PDF；扫描件无 OCR（仅原生文本）。
- 单文件默认上限 20MB。
- 部分浏览器对 `Intl.DateTimeFormat` 的 `dateStyle`/`timeZoneName` 组合不兼容；前端已改为显式字段并带降级。

B03 可复用：

1. 项目与材料 ID、页文本/页图 API
2. `app.llm.analyze_image`（页图 → 字段提取）
3. 前端详情页材料列表与预览壳
