## 2. 模块边界

| 层 | 行为 |
|---|---|
| 提取 | 原生 PDF 文本；申报书/预算表取文头标题，承诺书取「项目名称」字段；负责人取「项目负责人」字段 |
| 规范化 | Unicode 空白归一、首尾去除、连续空白合并；CJK 换行空格删除。不同义改写 |
| 比较 | 程序侧。两处及以上可靠值不同 → FAIL；缺材料或字段不可靠 → HUMAN；三处可靠且一致 → PASS |
| 契约 | `execute_identity_rule(Session, RuleExecutionContext) -> RuleExecutionResult` |
| 证据 | `ReviewEvidence`：材料、字段、原文、规范化值、页码、摘录、bbox |

扫描标题、手写姓名在原生文本中的标记视为不可靠，不调用视觉模型。
