## 2. 技术选型与模块边界

| 层 | 选型 | 边界说明 |
|---|---|---|
| 前端 | React + TypeScript + Vite + npm | 项目列表 / 创建 / 详情；无审查结果伪造 |
| 后端 | FastAPI + SQLAlchemy | REST API；启动时 `create_all`，不清空库 |
| 数据库 | SQLite 文件 `backend/data/app.db` | 普通启动与重启保留数据 |
| Python | `uv` + `backend/uv.lock` | 不向 system / user site-packages 安装 |
| 模型 | OpenAI 兼容客户端（实测 DashScope compatible-mode） | 仅服务端；配置：`LLM_BASE_URL` / `LLM_MODEL` / `LLM_API_KEY` / `LLM_TIMEOUT_SECONDS` |
| 结构化输出 | 请求侧 `response_format.json_schema` + 本地 Pydantic 校验 | “要求模型输出 JSON”不算完成校验 |

关键模块：

- 项目 API：`backend/app/api/projects.py`
- 持久化：`backend/app/models.py`、`backend/app/db.py`
- 图像适配器：`backend/app/llm/`（供 B02/B03 复用）
- 开发 smoke CLI：`backend/scripts/smoke_vision.py`（非产品页、非公开调试接口）

## 4. 复现步骤（启动 → 创建 → 刷新 → 重启）

```bash
# 后端
cd backend
export UV_PROJECT_ENVIRONMENT="$HOME/.venvs/guizheng-ai-backend"  # /mnt/d 等无 symlink 环境需要
export UV_LINK_MODE=copy
uv sync --extra dev --python 3.12
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000

# 前端
cd frontend
npm install --no-bin-links   # /mnt/d 需要
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`：创建项目 → 进入详情 → 刷新页面仍可见 → 重启后端后再查同一 ID。
